# Deep Audit — Widget/Tool Consistency, Guardrails, Display Gaps (2026-07-21)

48-agent deep-research workflow over this repo: 5 investigators (inventory
drift, router/resolvers, guardrails, client reconcile, display gaps), each
finding adversarially verified by an independent agent (28 CONFIRMED, 12
PARTIAL with corrections, 0 refuted), plus 3 widget-pack designers grounded in
factory.py idiom. This file is the condensed record; the fix wave that shipped
with it is described in HANDOFF.md.

## Verified findings (severity · status → disposition)

### Silent-success bugs (the worst class)
1. **Agent tier counted every mutation as committed** (high · CONFIRMED →
   **FIXED**). `execute_mutation` swallowed failures and both commit sites
   incremented `widgets_committed` unconditionally, so a hallucinated selector
   ended the turn with "Added it to your canvas." over an unchanged canvas.
   Now `mutation_outcome["committed"]` is set only when `commit_canvas`
   actually emits a component frame; failures surface a status line and leave
   the prose fallback armed.
2. **update_widget no-op'd with success on every factory widget** (high ·
   CONFIRMED → **FIXED**). `_update` only knows create_widget anatomy
   (`.glass-card-title`/`.widget-body`); on factory widgets nothing matched
   and it returned None → byte-identical commit reported as success. Now:
   factory-typed targets are rejected outright (model is told to use
   canvas_add_widget with the same id), and `touched` tracking aborts when no
   element matched.
3. **canvas_modify_dom edits were suppressed client-side** (high · PARTIAL →
   **FIXED**). DOM edits didn't change the widget root's `data-sig`, so
   reconcileCanvas saw "unchanged" and kept the stale node — server success,
   DB updated, screen frozen until reload. The modify/update paths now bump
   `data-sig` before committing.
4. **reconcileCanvas never painted create_widget glass-cards** (high ·
   CONFIRMED → **FIXED**). It selected only `.widget-container`; custom
   widgets are `.glass-card canvas-widget`, so they never appeared live and
   were never removed. Selector set now matches loadHistory's census
   (top-level `.widget-container, .glass-card, .canvas-widget`).
5. **Chart config destroyed on first render** (high · CONFIRMED → **FIXED**).
   The client replaced the hidden `<pre class="chart-config-block">` with the
   canvas; serialize→adopt then persisted a config-less chart that rendered
   blank after reload. The pre now stays (marked `data-chart-rendered`), the
   canvas is inserted as a sibling, and getCleanedCanvasHtml strips
   `.chart-container` + the marker so the canonical canvas always carries the
   pristine config.
6. **data-revived marker serialized into the canonical canvas** (medium ·
   CONFIRMED → **FIXED**) — custom-widget scripts never re-ran after one
   adopt+reload cycle. Stripped in getCleanedCanvasHtml.
7. **renderError wiped the whole canvas** (medium · CONFIRMED → **FIXED**) —
   and the wipe could be adopted server-side on the next message, deleting
   every widget. Now a transient, serialization-stripped error banner.
8. **Checklist edits lived only in Alpine memory** (medium · CONFIRMED →
   **FIXED**) — added tasks/toggles vanished on reload. checklistWidget now
   uses the notesWidget localStorage pattern (per-widget-id, server-baseline
   comparison; agent rewrites still win).

### Guardrails
9. **create_widget interpolated model title/html raw into live markup +
   `<script>`** (high · CONFIRMED → **HARDENED**). Title is now escaped and
   htmlContent runs through the same `audit_html_fragment` the notes path has
   always had (failed audit → rendered as escaped text). `jsContent` still
   executes — that IS the custom-widget feature — a full fix means srcdoc
   iframe isolation (backlog below).
10. **Canvas DOMPurify is architecturally permissive** (high · CONFIRMED →
    **DOCUMENTED, not changed**): `ADD_TAGS: ['script']` + the global hook
    force-keeping every `x-/@/:` attribute is what makes Alpine widgets and
    custom widgets work; removing it breaks the product. The real defense is
    upstream (escaping at render time, image/URL provenance, the audit in #9).
11. **render_iframe_app skipped esc() on title/icon** (medium · CONFIRMED →
    **FIXED**) — the one renderer that dropped config strings into raw markup.
12. **iframe sandbox granted allow-scripts + allow-same-origin over the
    same-origin reader** (medium · CONFIRMED → **FIXED**): allow-same-origin
    dropped; embeddable-host check now parses the URL (netloc+path) instead of
    substring-matching the whole string (`evil.com/?x=youtube.com/embed` used
    to frame directly).
13. **SSRF: /widgets/embed + read_web_page fetched arbitrary URLs** (medium ·
    CONFIRMED → **FIXED**): `_is_public_http_url` resolves the host and
    refuses loopback/RFC-1918/link-local/metadata targets before any
    server-side fetch.
14. **Scraped page text spliced unfenced into the summariser prompt** (medium
    · CONFIRMED → **FIXED**): sources are now fenced `<<<SOURCE n>>>…<<<END>>>`
    with an explicit treat-as-data instruction, and the prompt carries today's
    date (also closes part of the recency hole below).
15. **Tool whitelist fail-open + unauthenticated /internal/execute** (medium ·
    CONFIRMED → **OPEN, backlog**): prism forces core tools regardless of
    enabledTools (coreToolsLocked unreachable for CUSTOM agents) and
    /internal/execute dispatches on req.tool with no gate. Needs server-side
    allowlist enforcement + auth on the internal endpoint.

### Router / resolver consistency
16. **Prompt advertised 'music'/'embedded app' as widget types** (high ·
    PARTIAL → **FIXED**): routing line now names `mini_music_player` /
    `iframe_app`, and `_WIDGET_TYPE_ALIASES` in render_widget rescues
    near-miss types (music→mini_music_player, embed→iframe_app, …) instead of
    silently degrading to a data_card that dodges the media-singleton swap.
17. **THEME_INTENT_RE stole widget color edits** (medium · CONFIRMED →
    **FIXED**): "make it green" after a chart repainted the dashboard. The
    intercept now stands down when the client supplied a focus widget and the
    ask names no look-noun.
18. **_stream_settings never persisted the canvas** (medium · CONFIRMED →
    **FIXED**): theme turns now save the canvas block like every sibling path,
    so the panel survives reload.
19. **Recency guard existed only on the legacy fast path** (medium · CONFIRMED
    → **FIXED**): the tier-2 video branch now checks RECENCY_RE against the
    ORIGINAL message and searches order="date" first (relevance fallback);
    build_answer_config now knows today's date.
20. **products unreachable in prism mode** (medium · CONFIRMED → **FIXED**):
    removed from `_AGENT_RESEARCH_TYPES`, so the router's local builder runs
    in both modes and render_products is reachable again.
21. **Tier-2 router had no vocabulary for settings** (medium · PARTIAL →
    **FIXED**): defer rule now names theme/appearance/settings so those asks
    reach the agent (which knows the settings route) instead of a
    misclassified answer card.
22. **reminder/converter had no reuse policy** (low · CONFIRMED → **FIXED**):
    reminder is reuse-eligible (fast path now retargets the open countdown);
    converter deliberately excluded (user-owned state); stale "14 types"
    comment rewritten.
23. **Agent tier dropped P3 role-prefix reuse (traffic fork)** (medium ·
    CONFIRMED → **OPEN, backlog**): `_resolve_agent_widget_id` still doesn't
    pass id_prefix, so a traffic ask reaching tier 3 can stack a second
    traffic widget. Needs role-prefix derivation from the model id.
24. **Follow-up chain type-disagreement (verbatim-id bypass)** (high · PARTIAL
    → **OPEN, backlog**): when the model's widget_id names a live widget of a
    DIFFERENT type, the id is rejected by the type gate then honored verbatim
    by `_add` — an in-place type morph the guard was supposed to stop. Needs
    an explicit decision (honor as morph vs mint fresh) in
    `_resolve_agent_widget_id`.
25. **data-req-seq out-of-order guard covers only media** (medium · CONFIRMED
    → **OPEN, backlog**): weather/map/settings in-place replacements can still
    commit out of order under concurrent turns.
26. Cosmetics fixed: glitch skip-list now keyed on `data-widget-type` (the
    `.youtube-widget`/`.music-widget` selectors matched nothing), the debug
    widget-type logger reads the authoritative stamp, tools_schema.py carries
    a DEAD FILE header, music-player heights (h-[280px]/h-[420px]) stripped on
    serialize + self-heal.

### Display gaps → the new widget pack
The audit's capability matrix (tools fetch volumes/ratings/dates/matched
series; renderers could express almost none of it) produced 16 grounded
proposals; 7 shipped this wave — see HANDOFF.md. Notable still-open gaps:
stock volume underlay (fetched-but-dropped at factory.py's snapshot), map+list
split view for rated POIs, weather multi-city compare resolver, sports
standings tool (prompt promises standings; ESPN /standings endpoint never
fetched), gallery_facts / video_shelf / stat_card / calendar proposals.
